# backstop-field-test

A disposable repository for field-testing [Backstop](https://github.com/hjconsult/backstop).

Everything here is test data. Agents build through the gate, the runs are
measured, and findings go back into Backstop itself. Nothing in this repository
is a product, and nothing in it is fixed when it breaks — a run that went wrong
is discarded and repeated, never repaired.
